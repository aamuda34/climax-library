# CLIMAX Library

Updated working version for the current admin direction.

- Admin can read and download every uploaded book.
- Admin controls student download access per book.
- Every active student can access every published book.
- Student level/department remain profile information only; they do not restrict books.
- PDF and EPUB remain supported.

Run `supabase/20260909_library_access_downloads.sql` once in the CLIMAX Library Supabase SQL Editor before deploying this version.
